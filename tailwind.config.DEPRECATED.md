# Migrated to DaisyUI 5 - Tailwind CSS v4 Configuration

The `tailwind.config.mjs` file has been removed as it's deprecated in Tailwind CSS v4.
All configuration is now handled in `src/styles/global.css` as required by DaisyUI 5.

## New Configuration Location:
- **File**: `src/styles/global.css`
- **Method**: CSS-only configuration
- **DaisyUI Plugin**: `@plugin "daisyui"`

## Themes Configured:
- **Light Theme**: Default theme
- **Dark Theme**: Prefers dark mode

For more information, see the DaisyUI 5 documentation:
https://daisyui.com/docs/install/
